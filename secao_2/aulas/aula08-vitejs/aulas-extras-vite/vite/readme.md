<h1> Vitejs</h1>
<p>

pode ser usada em praticamente qualquer ambiente javascript com suporte tanto ao javascript puro quanto a maioria do frameworks como:

<ul>
  <li>React</li>
  <li>Vue</li>
  <li>Angular</li>
  <li>Svelte</li>
</ul>
